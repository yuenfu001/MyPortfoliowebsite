# Chiko Liu Portfolio

Responsive portfolio template using plain HTML, CSS and JavaScript.

## Files
- index.html
- css/style.css
- js/script.js

## Customize
- Replace `your-email@example.com` with your real email.
- Replace the LinkedIn/GitHub/Portfolio `#` links.
- Add real project links/screenshots where appropriate.
- Open `index.html` directly in a browser.

## Included
- Modern dark/light theme with saved preference
- Responsive navigation
- Scroll progress indicator
- Reveal-on-scroll animations
- Back-to-top button
- Copy-email interaction
- Responsive experience timeline
- Expertise, skills and project sections
